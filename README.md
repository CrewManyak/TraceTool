# TraceTool

**TraceTool**, Windows üzerinde Minecraft ile ilişkili dosyaları ve sistem izlerini incelemek, şüpheli aktiviteleri belirlemeye yardımcı olmak ve tarama sonuçlarını raporlamak amacıyla geliştirilen bir analiz aracıdır.

## Özellikler

- 🔍 Minecraft dosyaları ve modları üzerinde analiz
- 📂 JAR, ZIP, EXE ve DLL dosyalarını inceleme
- 🧾 Sistem ve uygulama kayıtlarını değerlendirme
- 📊 Tarama sonuçlarını görüntüleme ve raporlama
- 📄 HTML, JSON ve CSV formatlarında dışa aktarma
- 🌐 Çoklu dil desteği
- 🖥️ Windows için masaüstü arayüzü
- 🔄 Güncelleme altyapısı
